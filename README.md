# 安心广告管家

## 0.2.0 通用规则升级

内置 anti-AD 规则版本 20261111073636，109,239 条域名，来源 https://github.com/privacy-protection-tools/anti-AD ，许可证随 APK 位于 assets/ANTI-AD-LICENSE.txt，应用内也可查看。匹配使用哈希索引和域名标签边界，白名单优先于通用规则与额外拦截。

首页“更新通用广告规则”支持用户主动联网更新，GitHub 原始地址失败时尝试 jsDelivr 对应仓库镜像；不定时联网、不调度后台任务。下载有大小和超时限制，规则少于 10,000 条则拒绝；通过 HTTPS 获取，不提供额外发布者签名认证。校验后以 AtomicFile 保存，失败保留旧版本；下载期间 DNS 使用原规则。可以恢复安装包规则，保留自定义规则和白名单。

新增放行白名单，误拦时可添加可信域名及其子域名。仍为 DNS 层过滤，不能自动点击跳过，无法保证拦截缓存素材、硬编码 IP、独立加密解析或内容同域广告。阅坊和随手记尚未真机复测，不应将规则增加描述为已修复这两款应用。

下文“仅 11 条”描述对应 0.1 旧版；0.2.0 已用通用规则库增强。

0.1.1 新增“广告漏拦诊断”：显式开启后在内存中临时保留最近 100 个 DNS 查询及匹配结果，3 分钟到期后在下次访问记录时清除，也可立即手动结束清除。不持久化、不上传。仅用来收集漏拦线索，不代表已经修复阅坊或随手记广告；截图需先检查隐私。进程退出记录消失，后台无新请求且不访问结果时到期数据可能暂留内存。

面向家人的 Android 大字版广告辅助工具，Android 8.0 及以上。源代码不依赖第三方库。

## 安装

构建输出为 `dist/FamilyAdGuard.apk`。把 APK 传到手机，点击安装，按手机提示允许该来源安装。首次开启防护需要确认系统 VPN 授权。Android 13 以上建议允许通知，以便从通知栏停止防护。

只过滤发送至虚拟 DNS 的 IPv4 UDP DNS 查询，正常网络流量不经过远端 VPN；允许的查询通过 UDP 发送至阿里公共 DNS `223.5.5.5`。不提供 DNS 加密。上游不可达会返回 SERVFAIL，可关闭防护恢复系统 DNS。

不能拦住全部广告：应用内加密 DNS、直连 IP、缓存 DNS、IPv6 自带解析或广告与内容共用域名等会绕过。内置仅 11 条规则，可能漏拦或误拦。与其他 VPN 互斥；不要开启系统“阻止未使用 VPN 的连接”。不支持始终开启模式。重启后需手动开启。

“查找乱弹广告的软件”根据用户授权后的近期使用记录以及桌面应用声明的悬浮窗权限提供排查线索，不会自动判定恶意应用，也无法读取其他应用悬浮窗权限的实际授权状态。进入系统应用详情后自行关闭通知、权限或确认卸载。没有桌面入口的应用需在系统全部应用列表检查。

不申请 root、无障碍、设备管理员或自身悬浮窗权限。不自动卸载、不清除个人文件。不上传应用清单、不保存域名记录；本机只持久化规则、拦截请求计数、最近错误。可通过清除本应用数据删除。

## 构建与验证

Windows PowerShell：`./scripts/build.ps1`。默认使用本机 JDK 17 和 Android SDK 34，可通过 `-Jdk` 和 `-Sdk` 覆盖。执行纯 Java 协议测试、编译、DEX 转换、打包和签名验证。`build/local-test.jks` 是仅供个人测试的本机签名文件，密码为公开的 android，不适合商店发布；请保留该文件才能覆盖更新已有安装。

真机验证：开启后测试普通网页可用、命中内置规则的域名被阻止、停止后恢复；检查通知停止按钮、拒绝 VPN 授权、撤销 VPN、切换 Wi-Fi/移动网络、后台省电、使用情况权限拒绝和授予。只有构建和协议测试通过不能证明所有手机兼容，安装后仍需真机确认。
